RAHUL & SHAMAL — 5-PAGE BIRTHDAY WEBSITE

Files:
index.html = Home
memories.html = Polaroid photo gallery
quiz.html = Interactive five-question quiz with correct answers and score
letter.html = Birthday letter
surprise.html = Final birthday wishes
style.css and script.js = shared design, floating hearts and original browser-generated instrumental melody
quiz.js = quiz logic
assets/ = your four uploaded photos and pink background

PUBLISH FREE WITH GITHUB PAGES:
1. Create a PUBLIC repository named shamal-birthday.
2. Upload all five HTML files, CSS/JS files, README.txt and the complete assets folder.
3. Keep the assets folder and filenames unchanged.
4. Open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select main and /(root), then Save.
7. Your site link will look like https://YOUR-USERNAME.github.io/shamal-birthday/

MUSIC:
Tap “Play birthday music”. It plays an original gentle instrumental melody generated by the browser. A tap is required before audio can start.

PHOTOS:
The four uploaded photos are included in assets/. Replace them using the same filenames if you want different pictures.
